# MERQO — বাংলা পদাভিধান (Bangla Glossary)

এই ফাইল পুরো প্রোডাক্টের **ক্যাননিকাল (canonical) বাংলা শব্দভাণ্ডার**। একই ধারণার জন্য
একটাই শব্দ ব্যবহার হবে — কোথাও একটা, কোথাও অন্যটা নয়। `src/shared/glossary.ts` হলো
UI-এর সোর্স অফ ট্রুথ; এই ডকুমেন্ট সেই বাছাইয়ের কারণ সহ রেকর্ড।

**পরীক্ষার প্রশ্ন:** একজন বাংলাদেশি দোকানদার/ব্যবসায়ী এটাকে স্বাভাবিক ও পরিষ্কার
ভাষা হিসেবে পড়বেন কি?

## ৪. সংখ্যা, মুদ্রা, তারিখ

- মুদ্রা চিহ্ন: **৳** (এখনও ৳, $ নয়)। টাকা = ১০০ পাইসা; পুরো অ্যাপে ভাঙনহীন পাইসা (integer)।
- UI-তে সংখ্যা **বাংলা অঙ্কে** (০২৩৪৬৭৮, `<Bn>` কম্পোনেন্ট); ইনপুট ফিল্ডে ইংরেজি অঙ্ক গ্রহণযোগ্য।
- তারিখ: বাংলা মাস-দিবস ('১৫ সেপ্টেম্বর ২০২'), বর্ষ বাংলা সাধারণ (২০২৬)।
- সময়: ১২-ঘণ্টা ফরম্যাট, 'অব./পূ.' নয় — সিস্টেম ডিফল্ট।

## ৫. English-কীওয়ার্ড যেগুলো **রাখা** হয়েছে (উদ্দেশ্যমূলক)

POS, SKU, বারকোড, PDF, CSV, MFS (bKash/Nagad/…), COGS, ব্যালেন্স, পেমেন্ট, ট্রান্সফার,
অডিট, কমিশন, প্রভাইডার, ব্যাচ, নটিফিকেশন — এগুলো বাংলাদেশের ব্যবসায়ীরা স্বাভাবিকভাবেই
এভাবে বলে। এদের বাংলা-করণ (যেমন 'বারকোড' → 'বাধকোড') স্বাভাবিক না।

## ৬. বাক্য-নিয়ম (anti-robotic)

1. **চুড়ান্ত, চুড়ে-আনা বাক্য:** "লেনদেন সম্পন্ন করুন" — "লেনদেনের কার্যক্রম সম্পাদন করুন" নয়।
2. **সরাসরি কাজ বলুন:** "ব্যাকআপ থেকে তথ্য পুনরুদ্ধার" — "ডেটা পুনরুদ্ধার কার্যক্রম" নয়।
3. কারও-বাংলা শব্দ প্রাধান্য: 'বদলাবদল' নয় 'পরিবর্তন', 'হিসাব' নয় 'অ্যাকাউন্ট' (UI লেবেলে)।
4. দীর্ঘ বাক্য ভাগ করুন; দণ্ড/কমা সঠিক ব্যবহার; চূড়ান্ত বাক্যে '।'।
5. কোনো raw error/stack trace UI-তে নেই — চুড়ান্ত বাংলা বার্তা + লগ।
6. Bangla shaping/Unicode: সব টেক্স্ট Nirmala UI-ফ্রেন্ডলি Bangla Unicode; কোনো half-width
   Bangla character নয়।

## ৭. ধারাবাহিকতা যাচাই (consistency check)

নিচের প্রত্যাখ্যাত শব্দগুলো UI-কোডে **০** বার হতে হবে:

```sh
grep -rnE "মজুদ|গ্রাহক|সরবরাহকারী|রিটার্ন|আপডেট|ডিলিট|রিমুভ|এডিট|ক্যান্সেল|আমদানি|রপ্তানি" src/renderer --include="*.tsx"
# expectation: no output
```

একই ধারণা-বহু-শব্দ যাচাই (প্রতিটি ধারণা একটাই ক্যাননিকাল শব্দ):

```sh
grep -rn "ফেরত\|রিটার্ন" src/renderer --include="*.tsx"        # শুধু 'ফেরত'
grep -rn "হালনাগাদ\|আপডেট" src/renderer --include="*.tsx"     # শুধু 'হালনাগাদ'
grep -rn "স্টক শেষ\|শেষ স্টক" src/renderer --include="*.tsx"   # শুধু 'স্টক শেষ'
grep -rn "ইমপোর্ট\|আমদানি" src/renderer --include="*.tsx"      # শুধু 'ইমপোর্ট'
```

## ৮. পরিবর্তনের নীতি
