# Release Notes

## v1.0.0 — MERQO Business Suite (2026-09-16)

প্রথম পূর্ণাঙ্গ উৎপাদন সংস্করণ। সম্পূর্ণ অফলাইন Windows ডেস্কটপ অ্যাপ।

### নতুন / পুরোপুরি কার্যকর

- **ফার্স্ট-রান সেটআপ**: ব্যবসার তথ্য + মালিক অ্যাকাউন্ট তৈরি (মালিক ভূমিকা +
  ডিফল্ট ভূমিকা/অধিকার + সিস্টেম হিসাব + ক্যাটাগরি সিড)।
- **লগইন**: ইউজারনেম/পাসওয়ার্ড, ব্যর্থ চেষ্টায় লকআউট (ডিফল্ট ৫ বার / ১০ মিনিট)।
- **POS**: HID বারকোড স্ক্যান, অজানা বারকোড ক্যাপচার (পণ্য তৈরি-করা ফ্লো),
  ক্রেডিট লিমিট ওয়ার্নিং, মেয়াদোত্তীর্ণ ব্লক (সেটিংসে বন্ধ করা যায়),
  নগদ/ব্যাংক/MFS ধাপে পেমেন্ট, হোল্ড-রিস্যুম, রসিদ প্রিভিউ + PDF।
- **পণ্য**: CRUD, ক্যাটাগরি/ব্র্যান্ড/একক, SKU/বারকোড, খরচদাম/বিক্রয়মূল্য,
  প্রাইস হিস্টরি, সফট-ডিলিট।
- **ইনভেন্টরি**: ওয়েটেড-এভারেজ খরচদাম, স্টক অ্যাডজাস্টমেন্ট (কারণসহ, অডিটেড),
  ব্যাচ + মেয়াদ, রিকনসিলিয়েশন চেক (লেজার vs হিসাব)।
- **ক্রয়**: সাপ্লায়ারে পণ্য, স্প্লিট পেমেন্ট, বকেয়া, পিচেস রিটার্ন (স্টক-ফেরত)।
- **বিক্রয়ের হিসাব**: লিডজার, ডিটেইল, বাতিল (কারণ + স্টক-ফেরত), বিক্রয় ফেরত
  (রিস্টক অপশনসহ), রসিদ PDF।
- **কাস্টমার/সাপ্লায়ার**: লিডজার (running balance), কালেকশন/পেমেন্ট, ক্রেডিট
  লিমিট, প্রারম্ভিক বকেয়া/প্রদেয়।
- **খরচ**: ক্যাটাগরিভিত্তিক লেজার, কাস্টম ক্যাটাগরি।
- **হিসাব**: নগদ/ব্যাংক/MFS ব্যালেন্স, ট্রান্সফার, লেনদেন লিডজার।
- **শিফট**: খোলা-বন্ধ (কাউন্টেড ক্যাশ, ভ্যারিয়েন্স), হিস্টরি, দৈনিক ক্লোজিং
  (বিক্রয়/COGS/লাভ/খরচ)।
- **MFS এজেন্ট**: ক্যাশ-ইন/ক্যাশ-আউট/সেন্ড-মানি ম্যানুয়াল রেকর্ডিং, কমিশন
  নিয়ম (হার/স্থির, min/max), ওয়ালেট রিকনসিলিয়েশন।
- **রিপোর্ট**: বিক্রয় (দিনভিত্তিক চার্ট, মাধ্যম, পণ্য), লাভ-ক্ষতি, স্টক
  (মূল্য/মৃত/দ্রুত/মন্দ), হিসাব (ব্যালেন্স শিট, প্রাপ্য-দেনা), খরচ, কালেকশন —
  ড্যাশবোর্ডের সাথে একই ডোমেইন লজিক।
- **প্রিন্ট**: 58/80mm/A4 রসিদ HTML, PDF সেভ, ডিফল্ট প্রিন্টার সেটিংস।
- **ডেটা**: ব্যাকআপ তৈরি/যাচাই/রিস্টোর, CSV ইমপোর্ট (প্রিভিউ, ত্রুটি রিপোর্ট,
  কলাম ম্যাপিং), CSV এক্সপোর্ট, ডাটাবেস ইন্টিগ্রিটি চেক।
- **ব্যবহারকারী**: প্রোফাইল/পাসওয়ার্ড, ব্যবহারকারী CRUD, ভূমিকা-অধিকার এডিটর,
  অমুছ অডিট লগ।
- **সেটিংস**: ব্যবসার তথ্য, ফাইন্যান্সিয়াল নিয়ম (ট্যাক্স, নেগেটিভ স্টক…),
  POS/প্রিন্টার, রসিদ ফরম্যাট, নোটিফিকেশন, ব্যাকআপ ফোল্ডার, অ্যাপ তথ্য।

### নিরাপত্তা (v1 থেকেই)

- সব ফিন্যান্সিয়াল লেখা = এক SQLite ট্রানজেকশন (rollback + idempotency key)।
- RBAC (৬ ভূমিকা) — IPC লেভেলে চেক; মালিক সব অধিকার পান।
- লাভ/খরচদাম পেরমিশন-গেটেড; পাসওয়ার্ড salt+hash; অডিট ট্রেইল অমুছ।
- কোনো নেটওয়ার্ক কল নেই; সব ডেটা স্থানীয়।

### পরিচিত (known) — পরবর্তী সংস্করণে

- কোড সিগনিং (EV/standard) — বিতরণের আগে যোগ হবে।
- অটো-লক টাইমার (সেটিংস কী আছে; UI টাইমার পরে)।
- MFS লাইভ API — স্পেস অনুযায়ী ইচ্ছাকৃতভাবে নেই (ম্যানুয়াল রেকর্ডিং)।
